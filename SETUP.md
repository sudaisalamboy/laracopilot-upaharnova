# Setup Guide — Upaharnova (Laravel Digital Store)

> A Laravel 12 digital-products store generated by laraCopilot — featuring a storefront, checkout, order tracking with UTR verification, and a protected admin panel for products, orders, customers, categories, downloads, and analytics.

Made by **Sudais Alam**.

---

## Project Overview

**laracopilot-upaharnova** is a Laravel e-commerce application for selling digital products. Customers browse products, view product details, place orders, complete checkout, and track order status (with UTR/UPI transaction reference verification). Administrators manage products, orders, customers, categories, downloads, and view analytics through a dedicated admin panel.

---

## Prerequisites

- **PHP >= 8.2** (with `pdo_sqlite` or `pdo_mysql`).
- **Composer** — https://getcomposer.org
- **Node.js >= 18** + **npm** (for Vite asset building).
- A database: **SQLite** (default, zero-config) or **MySQL/MariaDB**.
- (Optional) **Docker** + **Docker Compose** (a `docker-compose.yml` is included).

---

## Installation

```bash
# 1. Clone
git clone https://github.com/sudaisalamboy/laracopilot-upaharnova.git
cd laracopilot-upaharnova

# 2. Install PHP dependencies
composer install

# 3. Install JS dependencies
npm install

# 4. Environment file
cp .env.example .env
php artisan key:generate

# 5. Configure your database in .env
#    SQLite (default): leave DB_CONNECTION=sqlite; a database.sqlite
#    file is created automatically under database/.
#    MySQL: set DB_CONNECTION=mysql and DB_HOST/PORT/DATABASE/USERNAME/PASSWORD.

# 6. Run migrations + seeders
php artisan migrate --seed
```

## Running Locally

```bash
# Terminal 1 — Laravel dev server
php artisan serve

# Terminal 2 — Vite (hot-reloading assets)
npm run dev
```

Visit **http://localhost:8000**.

| URL | Description |
|-----|-------------|
| `/` | Storefront home |

## Troubleshooting

| Problem | Fix |
|---------|-----|
| **`No application encryption key has been specified.`** | Run `php artisan key:generate`. |
| **`database.sqlite does not exist`** | Create it: `touch database/database.sqlite`, then re-run `php artisan migrate`. |
| **White page / 500 error** | Set `APP_DEBUG=true` in `.env` and check `storage/logs/laravel.log`. |
| **Assets not loading (Vite)** | Make sure `npm run dev` is running in a separate terminal. |
| **Admin pages accessible without login** | Add the `admin.auth` session-check middleware to the admin route group (the project already performs a session check — confirm `AdminAuthController` is wired up). |
| **UTR verification not saving** | Ensure the orders table has a `utr`/`utr_number` column (add a migration if missing) and that storage permissions are correct. |
| **`composer install` fails on PHP version** | Ensure PHP >= 8.2 (`php -v`). |
| **Permission denied on `storage/`** | `chmod -R 775 storage bootstrap/cache`. |
